# Logical English MCP Server Settings

Example client configurations for the Logical English MCP server:
`claude_desktop_config.json`, `claude_desktop_config_remote.json`,
`opencode_config.json.template` (used by the LE Assistant) and
`chatgpt_openapi.yaml` (ChatGPT actions over the REST endpoints).

How to set up a client, and the tools, resources and prompts the server
offers, are documented in [docs/user/api/mcp.md](../../docs/user/api/mcp.md).
