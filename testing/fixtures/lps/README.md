# Logical English for LPS: expected translations

`<name>.expected.lpsw` is the LPS internal syntax `le_lps.pl` must produce for
LPS2's example `examples/le/<name>.le` (testing/lps_test.pl, the M8c gate;
testing/lps_roundtrip.pl, M8d). The programs are read from an LPS2 checkout
when there is one; the few copied here (bank_transfer, token, fee_token, goat,
badlight with its companion) keep the gates running on LE2 alone.
