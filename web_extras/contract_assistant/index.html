LE Contract Assistant

Contract wording + schedule + cases → a tested Logical English knowledge base

1. Documents

Markdown or plain text preferred; Word (.docx) and PDF are converted on the server.

2. Existing LE code (optional)

Logical English you have already written — templates, scenarios with their expects answers lines, rules, facts, or any combination. It is treated as binding: the generated program must contain it and stay coherent with it, so the twin lines up with the program you started. Leave empty if you have none.

3. Model

Keys are kept in your browser (localStorage), shared with the LE editor, and sent only with your requests.

4. Additional instructions (optional)

Anything you want to tell the assistant in your own words. These go into every prompt that writes or repairs the program, and they override the house defaults where they conflict.

5. Effort budget

Cost estimate: choose a wording file to estimate
