# How the examples in this folder were made

All four programs, and both notes beside them, were written by an AI agent
(Claude, in Claude Code) for slides 5 to 8 of the talk *Logical Thinking in
the Age of AI*. The medical programs follow the guideline of a published
paper. The ethical programs write out an argument that the slides state in
English. Nobody has reviewed the programs yet, as the README says.

| File | Made by | How |
|---|---|---|
| `heart_failure.le`, `heart_failure_what_if.le` | AI agent (Claude, in Claude Code), 2026-09-14, at Miguel Calejo's request | Written from the heart failure guideline rules and the patient of Chen, Marple, Salazar, Gupta and Tamil, *A Physician Advisory System for Chronic Heart Failure Management Based on Knowledge Patterns* (2016, arXiv 1610.08115). |
| `provocation_transposed.le`, `standard_for_judgment.le` | AI agent (Claude, in Claude Code), 2026-09-14, at Miguel Calejo's request | Written from the argument on slides 7 and 8 of the talk. |
| `README.md`, `DETAILS.md` | AI agent (Claude, in Claude Code) | `DETAILS.md` maps each program to its slide. |
