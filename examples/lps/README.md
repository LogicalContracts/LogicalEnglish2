# Logical English for LPS

Programs in `the target language is: lps.` — actions, events, fluents and
reactive rules, run by LPS2 (docs/le_lps_surface.md). Each `.le` has its
expected LPS translation (`.expected.lpsw`, checked by testing/lps_test.pl) and,
for five of them, a `.lps` companion for what the English does not reach.
