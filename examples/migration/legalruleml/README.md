# LegalRuleML twins (Phase 2f)

Generated by `InsurLE2/migration/legalruleml/build.pl` — do not edit by hand;
see `InsurLE2/migration/legalruleml/README.md` for the mapping and the
results. One directory per example of the LegalRuleML Core Specification
(OASIS, 2021): the LE twin (`<name>.le`), the deontic library it includes
(`deontic.le`, a copy of LE2's `lib/deontic.le`), its ledger (`<name>.ledger.md`,
`.json`) and the source under `sources/` (File ▸ Show the Original). The
expected answers in the scenarios are SPINdle's (defeasible deontic logic) on
the source; the scenarios themselves were drafted from the examples'
paraphrases and the law they encode (LegalRuleML ships no tests).
