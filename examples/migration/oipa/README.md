# OIPA twins (Phase 2b)

OIPA is Oracle Insurance Policy Administration, a system that keeps
insurance policies and computes their transactions from an XML (Extensible
Markup Language) configuration.

Generated by `lpsPlus/migration/oipa/build.pl` — do not edit by hand; see
`lpsPlus/migration/oipa/README.md` for the mapping and the results. One
directory per transaction of the two synthetic plans (a deferred annuity, a
level term life policy): the LE twin (`<plan>_<transaction>.le`), the rate
tables it loads (`*.csv`), lib/temporal beside it, its ledger and the
configuration under `sources/`. The expected values in the scenarios are
computed by an independent interpreter of OIPA math (`oipa_eval.py`) playing
the plans' policy lives, never by the twin. The configuration is synthetic,
written from the forms of the public OIPA XML Configuration Guide 9.7; it is
not Oracle's.
