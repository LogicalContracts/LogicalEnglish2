# Bitcoin Miniscript twins (Phase 1d)

Generated by `InsurLE2/migration/miniscript/build.pl` — do not edit by hand;
see `InsurLE2/migration/miniscript/README.md` for the mapping, the sources and
the results. One directory per policy: the LE program (`<id>.le`, with the
policy's satisfaction analysis as scenarios, the key-loss flips and a
custody-explainer view), its migration ledger (`<id>.ledger.md`, `.json`), the
temporal library and `sources/`: the cited source excerpt, the page or files
it comes from whole (`originals/`), the policy as File ▸ Open takes it back
(`<id>.policy`) and the recorded run of its spending attempts on the public
Tape network (`<id>.chain.json`), which the program cites in its
chain-confirmed scenarios (`chain_…`). Each program also cites
`the policy in Minsc`, a link that opens the policy in the Minsc playground. Each program's header shows the
source policy verbatim, laid out as an indented tree with keys by role, the
key legend, and what the policy says in words.
