# Library shims for the WebAssembly build

SWI-Prolog's WebAssembly image is the full system minus the parts that need an
operating system underneath: no threads, no sockets, no sub-processes, no
timers. Nine libraries LE2 imports are therefore missing from it, and a missing
library is a *load* failure — the module that imports it does not exist, and
neither does everything above it.

Each file here stands in for one of them. They are on the library search path
of the WASM build only (`le_wasm.pl` appends it), so the server build never
reaches them: a real library is always found first.

Two things outside this directory did change for their sake, and both are
improvements on a server too. Four files (`le_kbs.pl`, `le_api.pl`,
`classic_web_api.pl`, `le_contract_assistant.pl`) now import `library(time)`
explicitly instead of leaving `call_with_time_limit/2` to the autoloader; and
`tokenizer:word_char/1` no longer trusts `code_type(C, csym)`, which the C
library gets wrong for non-ASCII letters here *and* on a server started under
`LANG=C`.

| Shim | Stands in for | What it does instead |
|------|---------------|----------------------|
| `time.pl` | `library(time)` | bounds a goal by *inferences* rather than seconds |
| `process.pl` | `library(process)` | refuses: there are no sub-processes in a browser tab |
| `www_browser.pl` | `library(www_browser)` | opens a tab through the host page |
| `http/json.pl` | `library(http/json)` | re-exports `library(json)`, which the image has |
| `http/http_json.pl` | `library(http/http_json)` | the JSON half; the reply half refuses |
| `http/http_open.pl` | `library(http/http_open)` | fetches through the browser, synchronously |
| `http/http_client.pl` | `library(http/http_client)` | `http_post/4` over the above |
| `http/http_ssl_plugin.pl` | `library(http/http_ssl_plugin)` | nothing: the browser's TLS is already on |
| `http/http_session.pl` | `library(http/http_session)` | no sessions: every request is anonymous |

`INDEX.pl` here is generated by `wasm/build.sh` (`make_library_index/1`) and
is not in the repository: it is what lets the autoloader find a shim predicate
that some file calls without importing it, which is how the four callers of
`call_with_time_limit/2` reached `library(time)` before any of this existed.

The rule for adding one: a shim provides *what this repository actually calls*,
and what it cannot do it must refuse in the same shape the real library would —
so that the code above it takes the path it would take on a server where the
thing failed, rather than a path nobody has tested.
